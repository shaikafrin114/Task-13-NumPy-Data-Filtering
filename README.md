## Concepts Covered

- Boolean conditions

- Filtering values below or equal to a threshold
- Filtering with multiple conditions
- Filtering student marks and sales data

## Example
```python
import numpy as np

marks = np.array([35, 45, 50, 60, 75, 80, 90, 95])

print(marks[marks > 50])
```

Output:
```text
[60 75 80 90 95]
```
